# การทดลอง Machine Learning: ประเมินผลตามลำดับเวลา

**สถานะ:** กรณีศึกษาผลการทดลองเดิม + โค้ดตัวอย่าง ML ที่รันซ้ำได้ด้วยข้อมูลสังเคราะห์  
**เทคโนโลยี:** Python, Random Forest, LightGBM, Chronological Test, ROC AUC, Brier Score

## คำถามวิจัย

โมเดลจำแนกประเภทสามารถช่วยให้การตัดสินใจของระบบอัตโนมัติดีกว่าวิธีพื้นฐานได้หรือไม่? เป้าหมายของหน้าผลงานนี้คือโชว์ **การฝึก การประเมิน และการตีความผลอย่างมีวิจารณญาณ** ไม่ใช่อ้างว่า AI เทรดทำกำไรได้

## ผลการทดลองเดิมที่ตรวจสอบพบ

ข้อมูลมาจากไฟล์ `ML_Chronological_Test_Metrics_APPROX.csv` ที่ตรวจพบในเครื่องวันที่ **11 พฤศจิกายน 2026** ใช้การแบ่งข้อมูลตามลำดับเวลา และป้ายกำกับผลลัพธ์ **ประมาณจากแท่งราคา M1** ไม่ใช่ผลการส่งออเดอร์จริงหรือ Live Forward Test

| โมเดล | จำนวนรายการใน Test | ROC AUC | Brier Score |
|---|---:|---:|---:|
| Random Forest | 449 | 0.5365 | 0.2362 |
| LightGBM | 449 | 0.5279 | 0.2379 |

**สิ่งที่เรียนรู้:** AUC สูงกว่า 0.5 เพียงเล็กน้อย สะท้อนว่าความสามารถในการแยกกลุ่มยังอ่อน และผลการทดลองแบบประมาณพบว่าการให้โมเดลเปลี่ยนการตัดสินใจ **แย่กว่าวิธีพื้นฐานเดิม** จึงยังไม่มีหลักฐานว่าโมเดลช่วยเพิ่มผลกำไรหรือใช้ได้ดีสม่ำเสมอ

**ข้อจำกัด:** จำนวนข้อมูลทดสอบจำกัด ความสัมพันธ์ของข้อมูลตามเวลา ผลกระทบจากต้นทุนและ Slippage และการประมาณจาก OHLC ที่อาจไม่ตรงกับลำดับ Tick จริง ข้อมูลและโค้ด EA จริง **ไม่ได้อัปโหลด**

## ตัวอย่างโค้ดฝึก ML ที่รันได้จริงและไม่เปิดเผยข้อมูลลับ

เพื่อโชว์ทักษะด้าน Machine Learning มีโปรเจกต์ตัวอย่างแยกต่างหาก ใช้ **ข้อมูลเซนเซอร์โรงงานสังเคราะห์ทั้งหมด** ไม่ใช่ข้อมูลราคา ตลาดทองคำ หรือ EA จริง

[โค้ดฝึกโมเดล](../examples/synthetic_ml_training.py) · [Unit Tests](../tests/test_synthetic_ml_training.py) · [ไลบรารี](../requirements-ml.txt)

ขั้นตอนประกอบด้วยสร้างข้อมูล 2,400 รายการ แบ่งตามเวลา Train 60% / Validation 20% / Test 20% จากนั้นฝึก Random Forest และ LightGBM และเทียบกับ Baseline ด้วย ROC AUC และ Brier Score

```bash
python -m pip install -r requirements-ml.txt
python examples/synthetic_ml_training.py
python -m unittest discover -s tests -v
```

ผลรันเดโมข้อมูลสังเคราะห์ในสภาพแวดล้อมทดสอบ:

| โมเดล | Validation AUC | Test AUC | Test Brier |
|---|---:|---:|---:|
| Baseline | 0.5000 | 0.5000 | 0.2502 |
| Random Forest | 0.7531 | 0.7720 | 0.1971 |
| LightGBM | 0.7547 | 0.7777 | 0.1948 |

**ห้ามเข้าใจผิด:** ผลข้างต้นเป็นข้อมูลจำลองที่สร้างขึ้นเพื่อทดสอบการทำงานของ ML เท่านั้น ไม่ใช่ประสิทธิภาพ EA จริงหรือผลกำไรจากการเทรด ส่วน Unit Tests ใหม่ผ่าน 5/5 รายการเมื่อรันในสภาพแวดล้อมทดสอบในเครื่อง

## การใช้ AI ช่วยพัฒนา

ใช้ AI ช่วยร่างโค้ดและเอกสาร แต่มีการรัน `model.fit` ประเมินชุดทดสอบที่กันไว้ และเขียน Unit Tests เพื่อให้ตรวจสอบได้ ผู้ทำโครงงานควรอธิบาย Baseline, Data Leakage, วิธีแบ่งข้อมูล, AUC/Brier และสาเหตุที่ผลทดลองยังไม่ดีได้ด้วยตัวเอง

**บทเรียน:** การทดลองที่ผลไม่ดีกว่าวิธีเดิมก็เป็นหลักฐานความสามารถในการวิจัยและ Software Engineering ได้ หากนำเสนอความจริงและข้อจำกัดอย่างโปร่งใส
